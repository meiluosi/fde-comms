**结论：这两条先记为"冲突"，不取平均，也不判谁对。** 现在只能确认两个人这样说过，不能确认"核对"这一步到底多久。

最需要你定的一点：**两人说的"核对"是不是同一段流程、同一类单据？** 你要是当场没问过，这就是下一轮最先要补的，因为它决定这是真冲突还是口径不同。

## 证据条目（可交给 fde-problem-framing）

| 字段 | E1 | E2 |
|---|---|---|
| 命题 | 核对一步一般约 10 分钟 | 核对经常要 20 多分钟，且经常超时 |
| 状态 | **假设**（对方的说法，无实物或日志支持） | **假设**（同左） |
| 来源 | 班长岗位，口头访谈 | 专员岗位，口头访谈 |
| 日期 | 周二下午（具体日期待补） | 周三上午（具体日期待补） |

| 单位 / 分母 / 时间窗 | 分钟；"一般"指什么（中位数、典型、规定值）未知；没有时间窗 | 分钟；"经常"是多大比例未知；"老超"超的是什么标准未知；没有时间窗 |
| 限制 | 口述；"一般"可能指标准情况或自己做的时候 | 口述；"经常/老超"是印象，可能偏向近期或印象深的单 |
| 后续动作 | 见下 | 见下 |

**E1 与 E2 的关系：冲突。** 不平均，不写成"10 到 20 多分钟"。原因待核对，下面几种都有可能，现在没有证据偏向任何一种：
1. 流程边界不同：一个只算动手核对，另一个把等待、返工、补资料也算进去。
2. 样本不同：一个说典型单，一个说麻烦的单（长尾）。
3. 做的人不同：班长说的可能是规定或自己的做法，专员说的是日常实际。
4. 时间窗不同：说的可能不是同一个时期。

这些只是待查方向，不是推断结论。

## 下一轮种子问题（用来消除冲突）
- 请两位各带你走一遍**最近实际处理的一单**，从哪一刻开始计时、到哪一刻算核对完，让双方的起止点对上。
- 追问频次："超"是超过什么标准？最近一个月大概几单、占多少？
- 如果有实物或日志（系统时间戳、工单记录、核对表），这是最便宜的裁决方式，先问有没有，再决定要不要再访谈。
- 不要向任何一方转述另一方的说法，也不要当面对质。

## 保密提醒
来源只写岗位，不写姓名。但"班长"和"专员"在小团队里可能直接对应到个人，所以：
- 汇总前先看这两个岗位是否只有一个人，是的话再粗化（如"一线人员"）。
- 专员的"还老超"是对工作表现的评价，不要写进班长或其上级可能读到的任何文件。
- 动机只作假设：班长可能不愿承认流程耗时，专员可能夸大。这类猜测只用于调整你的核对方式，不写进外部可见的文件。
